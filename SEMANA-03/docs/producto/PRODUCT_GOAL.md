# Product Goal

## Objetivo del producto

Desarrollar una aplicación móvil que permita a los usuarios gestionar de manera sencilla y organizada el registro y consulta de información, facilitando el acceso a las funcionalidades principales del sistema desde un dispositivo móvil.

## Problema que se busca resolver

Actualmente, la gestión de información puede realizarse de manera manual o mediante procesos poco organizados, lo que puede generar pérdida de tiempo, errores y dificultades para consultar la información.

La aplicación busca centralizar estas operaciones en una solución móvil sencilla, accesible y fácil de utilizar.

## Usuarios objetivo

- Usuarios registrados en la aplicación.
- Administradores encargados de gestionar la información.
- Personas que necesitan consultar o registrar información mediante un dispositivo móvil.

## Valor que aporta el producto

El producto permitirá:

- Centralizar la información en una sola aplicación.
- Facilitar el registro y consulta de datos.
- Reducir errores en la gestión de información.
- Mejorar la rapidez de acceso a las funcionalidades.
- Proporcionar una interfaz sencilla y accesible desde dispositivos móviles.

## Criterios de éxito

El producto será considerado exitoso cuando:

1. Los usuarios puedan acceder de forma segura a la aplicación.
2. Los usuarios puedan registrar y consultar información.
3. Las funcionalidades principales sean fáciles de utilizar.
4. La información sea gestionada de manera organizada.
5. La aplicación responda adecuadamente ante errores de conexión y del servidor.

## Relación con el Product Backlog

El Product Backlog se organizará y priorizará en función del valor que cada funcionalidad aporte al cumplimiento de este Product Goal, considerando también el riesgo, la seguridad y el tratamiento de datos personales.
