# HU-002 — Cerrar sesión

## Historia de usuario

Como usuario quiero cerrar sesión para proteger mi cuenta.

## Criterios de aceptación

### Escenario 1: Datos presentes

Dado que el usuario tiene una sesión activa
Y se encuentra dentro de la aplicación
Cuando selecciona la opción "Cerrar sesión"
Entonces el sistema cierra la sesión correctamente
Y redirige al usuario a la pantalla de inicio de sesión.

### Escenario 2: Datos vacíos o sesión inexistente

Dado que el usuario no tiene una sesión activa
Cuando intenta acceder a la opción "Cerrar sesión"
Entonces el sistema informa que no existe una sesión activa
Y mantiene al usuario fuera de las áreas protegidas.

### Escenario 3: Sin conexión

Dado que el usuario tiene una sesión activa
Y el dispositivo no tiene conexión a Internet
Cuando selecciona la opción "Cerrar sesión"
Entonces el sistema informa que no existe conexión
Y evita dejar información sensible expuesta.

### Escenario 4: Error del servidor

Dado que el usuario tiene una sesión activa
Y ocurre un error en el servidor
Cuando selecciona la opción "Cerrar sesión"
Entonces el sistema muestra un mensaje de error
Y evita exponer información técnica sensible.

## Definición de terminado

- La sesión se cierra correctamente.
- El usuario no puede acceder nuevamente a áreas protegidas sin autenticarse.
- Los escenarios de aceptación han sido verificados.
- Los errores se muestran de forma comprensible.
- No se exponen datos sensibles.
