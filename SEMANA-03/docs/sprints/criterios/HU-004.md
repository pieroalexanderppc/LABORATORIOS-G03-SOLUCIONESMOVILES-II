# HU-004 — Registrar usuarios

## Historia de usuario

Como administrador quiero registrar usuarios para gestionar el acceso al sistema.

## Criterios de aceptación

### Escenario 1: Datos presentes y válidos

Dado que el administrador se encuentra en el formulario de registro de usuarios
Y proporciona todos los datos obligatorios con información válida
Cuando selecciona la opción "Registrar usuario"
Entonces el sistema valida la información ingresada
Y registra correctamente al nuevo usuario.

### Escenario 2: Datos vacíos

Dado que el administrador se encuentra en el formulario de registro de usuarios
Y deja uno o más campos obligatorios vacíos
Cuando selecciona la opción "Registrar usuario"
Entonces el sistema solicita completar los campos obligatorios
Y no registra al usuario.

### Escenario 3: Sin conexión

Dado que el administrador proporciona datos válidos
Y el dispositivo no tiene conexión a Internet
Cuando selecciona la opción "Registrar usuario"
Entonces el sistema informa que no existe conexión
Y no procesa el registro.

### Escenario 4: Error del servidor

Dado que el administrador proporciona datos válidos
Y ocurre un error en el servidor
Cuando selecciona la opción "Registrar usuario"
Entonces el sistema muestra un mensaje de error
Y no expone información técnica sensible.

## Definición de terminado

- Los campos obligatorios son validados.
- Los datos válidos permiten registrar el usuario.
- Los datos incompletos son rechazados.
- Se contemplan problemas de conexión y servidor.
- No se exponen datos sensibles.
- Los criterios de aceptación han sido verificados.
