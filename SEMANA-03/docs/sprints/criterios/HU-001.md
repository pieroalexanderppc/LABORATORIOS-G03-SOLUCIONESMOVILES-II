# HU-001 — Inicio de sesión

## Historia de usuario

Como usuario quiero iniciar sesión para acceder de forma segura a la aplicación.

## Criterios de aceptación

### Escenario 1: Datos presentes y credenciales válidas
Dado que el usuario se encuentra en la pantalla de inicio de sesión
Y proporciona un correo y contraseña válidos
Cuando selecciona la opción "Iniciar sesión"
Entonces el sistema valida las credenciales
Y permite el acceso a la aplicación.

### Escenario 2: Datos vacíos
Dado que el usuario se encuentra en la pantalla de inicio de sesión
Y deja vacío el correo o la contraseña
Cuando selecciona la opción "Iniciar sesión"
Entonces el sistema solicita completar los campos obligatorios
Y no permite el acceso a la aplicación.

### Escenario 3: Sin conexión
Dado que el usuario proporciona credenciales válidas
Y el dispositivo no tiene conexión a Internet
Cuando selecciona la opción "Iniciar sesión"
Entonces el sistema informa que no existe conexión
Y no permite completar el inicio de sesión.

### Escenario 4: Error del servidor
Dado que el usuario proporciona credenciales válidas
Y ocurre un error en el servidor
Cuando selecciona la opción "Iniciar sesión"
Entonces el sistema muestra un mensaje de error
Y no expone información técnica sensible.

## Definición de terminado

- La historia cumple los cuatro escenarios de aceptación.
- Los datos de entrada son validados.
- Los errores se muestran de forma comprensible.
- No se exponen datos sensibles.
- La funcionalidad ha sido revisada por otro integrante del equipo.
