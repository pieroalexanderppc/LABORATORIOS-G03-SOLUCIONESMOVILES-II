# HU-005 — Consultar usuarios registrados

## Historia de usuario

Como administrador quiero consultar usuarios registrados para conocer las cuentas existentes.

## Criterios de aceptación

### Escenario 1: Datos presentes

Dado que el administrador se encuentra en la sección de usuarios
Y existen usuarios registrados en el sistema
Cuando selecciona la opción "Consultar usuarios"
Entonces el sistema muestra la lista de usuarios registrados
Y presenta la información permitida para el administrador.

### Escenario 2: Datos vacíos

Dado que el administrador se encuentra en la sección de usuarios
Y no existen usuarios registrados
Cuando selecciona la opción "Consultar usuarios"
Entonces el sistema muestra un mensaje indicando que no existen usuarios
Y no presenta una lista vacía como si fuera un error.

### Escenario 3: Sin conexión

Dado que el administrador solicita consultar los usuarios
Y el dispositivo no tiene conexión a Internet
Cuando selecciona la opción "Consultar usuarios"
Entonces el sistema informa que no existe conexión
Y no procesa la consulta.

### Escenario 4: Error del servidor

Dado que el administrador solicita consultar los usuarios
Y ocurre un error en el servidor
Cuando selecciona la opción "Consultar usuarios"
Entonces el sistema muestra un mensaje de error
Y no expone información técnica sensible.

## Definición de terminado

- La lista de usuarios se muestra correctamente cuando existen registros.
- Se informa adecuadamente cuando no existen usuarios.
- Se contemplan problemas de conexión y servidor.
- Solo se muestra información permitida al administrador.
- No se exponen datos sensibles.
- Los criterios de aceptación han sido verificados.
