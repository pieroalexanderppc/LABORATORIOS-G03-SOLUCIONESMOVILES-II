# HU-003 — Recuperar contraseña

## Historia de usuario

Como usuario quiero recuperar mi contraseña para volver a acceder a mi cuenta.

## Criterios de aceptación

### Escenario 1: Datos presentes

Dado que el usuario se encuentra en la pantalla de recuperación de contraseña
Y proporciona un correo registrado
Cuando selecciona la opción "Recuperar contraseña"
Entonces el sistema valida el correo
Y confirma que se ha enviado el proceso de recuperación.

### Escenario 2: Datos vacíos

Dado que el usuario se encuentra en la pantalla de recuperación de contraseña
Y deja vacío el campo de correo
Cuando selecciona la opción "Recuperar contraseña"
Entonces el sistema solicita completar el campo obligatorio
Y no procesa la solicitud.

### Escenario 3: Sin conexión

Dado que el usuario proporciona un correo registrado
Y el dispositivo no tiene conexión a Internet
Cuando selecciona la opción "Recuperar contraseña"
Entonces el sistema informa que no existe conexión
Y no procesa la solicitud.

### Escenario 4: Error del servidor

Dado que el usuario proporciona un correo registrado
Y ocurre un error en el servidor
Cuando selecciona la opción "Recuperar contraseña"
Entonces el sistema muestra un mensaje de error
Y no expone información técnica sensible.

## Definición de terminado

- Se valida el correo ingresado.
- La solicitud de recuperación se procesa correctamente.
- Se contemplan datos vacíos, falta de conexión y error del servidor.
- No se exponen datos sensibles.
- Los criterios de aceptación han sido verificados.
